---

## How entries are organized

By value category:

1. **Audio Quality** — upgrades that move the build from "guitar pedal
   reverb" to "Valhalla reverb", from "stock synth" to "Omnisphere /
   Keyscape" tier.  Highest-value category per user direction.
2. **Performance / Efficiency** — eliminate chop / lag / latency.
   Make the audio engine + UI more efficient on end-user hardware.
3. **User Tools / Learning Experience** — features that help beginners
   make music faster, with less friction, with better feedback.
4. **Workflow Polish** — UX improvements that don't fit the above
   categories but improve daily-use feel.
5. **Considered & Dropped** — items raised but not pursued, with reason.
   Prevents re-litigation when the same idea surfaces again.
