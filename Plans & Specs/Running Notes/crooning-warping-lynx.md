- **Finding (PV hop-rounding drift):** `PhaseVocoder::setStretchRatio` integer-rounds `mSynthHop`, so the EFFECTIVE stretch ratio is `synthHop/kHop`, not the request — a raw `preN*ratio` skip + `srcN*ratio` length map drifts ~0.1% (~23 ms over 60 s at ratio 0.9). Offline path computes `effRatio` from the rounded hop and force-resamples each span to its exact device-sample length. (Realtime path already immune — it re-anchors per block.)
- **Design choices (logged, not spec calls — analysis-source semantics):** block-level `muted` respected (user content decision); strip/row mutes + choke IGNORED (aligning while monitoring muted is the normal workflow); ClipsPage per-clip control chain (pitch/reverse/sampleStart knobs) NOT applied — composite is an analysis/alignment source, not a playback render.
