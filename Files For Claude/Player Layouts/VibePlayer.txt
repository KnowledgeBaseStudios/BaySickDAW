This layout is significantly more straightforward than the last one. Structuring this for Vibesynth will be a breeze in JUCE, especially since the entire main interface neatly subdivides into four distinct flex columns. You can easily map this out for Claude and swap in your own custom chicken-head knob assets to maintain that skeuomorphic hardware feel for the standalone app.

Here is the topographical breakdown you can feed to your AI assistant to generate the `juce::Component` hierarchy:

### **1. Top Header Area**
This section acts as the global control bar for the instrument.

* **Title Label:** Large text reading "FL KEYS" (left-aligned).
* **Preset Manager:** 1 Dropdown Menu / `juce::ComboBox` displaying the current loaded sample/patch (e.g., "Grand Piano (3 MB)") (right-aligned).
* **Help Button:** 1 Small square `juce::TextButton` or `juce::ImageButton` with a "?" icon (far right, adjacent to the preset manager).

### **2. Main Body (Four-Column Grid)**
The lower section is divided into four distinct vertical panels, each with its own header label. A horizontal `juce::FlexBox` containing four child components will handle this perfectly.

**Column 1: ENVIRONMENT**
*(Note: Spelled "ENVIROMENT" in the graphic, but you'll likely want to correct that in your code).*
* **Header:** Text Label ("ENVIROMENT").
* **Top Row:** 2 Standard Knobs (`DECAY`, `RELEASE`).
* **Bottom Row:** 2 Standard Knobs (`PAN`, `STEREO`).
    * *Detail:* The `PAN` knob features an outer ring, suggesting it might be a bipolar slider or have a center-detent visual indicator.

**Column 2: MISC**
* **Header:** Text Label ("MISC").
* **Top Row:** 2 Standard Knobs (`OVERDRIVE`, `LFO`).
* **Bottom Row:** 2 Standard Knobs (`TREBLE`, `STRETCH`).

**Column 3: VELOCITY**
This column handles dynamic response and has a slightly asymmetrical layout with routing graphics.
* **Header:** Text Label ("VELOCITY").
* **Top Row:** 2 Standard Knobs (`VEL`, `MUFFLE`). There is a small routing arrow graphic indicating `VEL` modulates `MUFFLE`.
* **Bottom Row:** 3 Standard Knobs (`VEL`, `HARDNESS`, `SENS`). Similar to the top row, a routing arrow indicates the bottom `VEL` modulates `HARDNESS`. 

**Column 4: TUNING**
A narrower column dedicated to pitch.
* **Header:** Text Label ("TUNING").
* **Top Row:** 1 Standard Knob (`TUNE`).
* **Bottom Row:** 1 Standard Knob (`DETUNE`).

**Prompting Tip for Claude:** Tell Claude to create a main container with a `juce::Grid` or `juce::FlexBox` set to `FlexBox::Direction::row` for the four columns. For the columns themselves, have it use `FlexBox::Direction::column`. You can also specifically instruct it to draw standard `juce::Label` components for the routing arrows in the Velocity section if you aren't using custom image assets for those indicators.
