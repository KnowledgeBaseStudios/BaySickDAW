A flavors the difference between every algorithm via NEW CODE
B flavors only via parameter values (same code throughout)
C is mixed: Plate gets the new-code treatment because it's the most worth-it; the other four are parameter-flavored siblings
Hall vs Chamber vs Room vs VocalBooth — these four share the same underlying topology (FDN) in real life too. A. Honest answer.

Pro shipping reverbs (Valhalla VintageVerb, Lexicon, UAD Plate 140, FabFilter Pro-R) all have separate DSP per algorithm. C is a workable shortcut, but the four FDN-based "algorithms" end up sounding suspiciously alike — same modal density, same diffusion character, same texture under decay. Trained ears notice immediately. Beginners might not, but you said this app's quality bar matters.

The cost of A vs C is real: ~2-3× the DSP work. Each algorithm needs its own topology design, coefficient tuning, listening passes, and state save/load. But it's the difference between "BaySickDAW has 5 reverbs" and "BaySickDAW has 5 reverbs that are actually distinct."
