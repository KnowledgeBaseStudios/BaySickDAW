# Keybinds & Feature Plan — Approved Scope (2026-04-26)

## Phase A — Keybind Framework (foundation, 1 session)

- `juce::ApplicationCommandManager` + `juce::KeyPressMappingSet` registered at editor startup.
- Each command: stable `CommandID` enum, default shortcut, category (General / Builder / Piano Roll / Mouse-Reference), action label, **tooltip string**.
- Persisted to `Documents/BaySickDAW/keymap.xml`. Loads on startup; saves on every edit.
- Help menu gets new entry **"Key Binds"** → opens a `DocumentWindow` containing a `juce::TabbedComponent` with three tabs:
  - **General** (~30 entries)
  - **Builder Page** (~32 entries)
  - **Piano Roll** (~50 entries)
- Each tab embeds `juce::KeyMappingEditorComponent` for editable shortcuts + conflict warnings + Reset-to-Defaults.
- Mouse-modifier rows appear inside each tab as a separate non-editable list at the bottom labelled **"(mouse — fixed)"**, documentation only.
- Every keybind row gets `setTooltip` (full tooltip text drafted in the previous response, ~120 entries).
- Phase A initially registers only the keybinds that already work — gives you a working editor immediately, then later phases add more entries to it.

## Phase C — Simple New Keybinds (hook into existing code)

- Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S → call existing `doFileNew/Open/Save/SaveAs`.
- Ctrl+M → toggle metronome.
- Alt+I → import MIDI file (replaces spreadsheet's Ctrl+M).
- Home → seek transport playhead to bar 0 (works in Pattern AND Song mode).
- "+" / "-" → cycle to next/prev pattern in `mPatternManager`, wraps; disabled when piano roll has focus.
- F3 → move pattern dropdown to first empty pattern.
- L → toggle Pattern↔Song transport mode.
- NumPad 0 → fast-forward by 4 bars per press.
- NumPad / and \* → ±1 bar playhead nudge, **only in Song mode**.
- Mouse-wheel / Shift+Mouse-wheel → already default JUCE behavior; documented only.

## Phase D — New Feature Builds (each its own session unless tiny)

### D-1: Builder per-block mute & quantize
- Add `bool muted` to `ArrangementBlock`. Muted blocks paint at 30% alpha + diagonal stripes; render path skips them.
- Alt+M / Alt+Shift+M → mute / unmute selection. Right-Alt+Left-click also mutes.
- Right-Alt+Right-Click → quantize popup (snap unit: bar / half-bar / beat / step).
- Ctrl+Shift+Right-Click → fit selected block to viewport.
- Ctrl+Right-Click drag → drag-rect zoom-fit.

### D-2: Time markers + per-bar time signatures (Builder)
- New `PatternManager::TimeMarker { int bar; juce::String label; }` list.
- New `PatternManager::TimeSigChange { int bar; int num; int den; }` list.
- Builder ruler renders flag glyphs for both. Right-click ruler → menu: "Add Time Marker", "Add Time Signature Change", "Edit...", "Delete".
- Hover marker → tooltip with label. Right-click marker → rename.
- Alt+T = add time marker at playhead. Shift+Alt+T = add TS change at playhead.
- Persisted in project XML.

### D-3: Performance Mode (Builder, Ctrl+P)
- FL-style live-clip-trigger mode.
- Each pattern in the Patterns dropdown becomes triggerable: clicking a row launches that pattern at the next bar; queue display flashes the pending one.
- Standalone session — needs UI design pass (clip launchers, queue indicator, optional MIDI keymap for triggering).

### D-4: Typing keyboard → MIDI (global, Ctrl+T)
- QWERTY layout, 2-octave range, FL-style: `Z X C V B N M` = white keys lower octave, `Q W E R T Y U` = white keys upper octave, `S D G H J` and `2 3 5 6 7` = sharps/flats.
- Routes to whichever engine has focus (last-played/last-edited piano roll's engine).
- Alt+NumPad 2-6 → shift base octave (octaves 2-6 of MIDI range).
- **Trade-off:** while typing-keyboard mode is ON, all letter shortcuts (B/C/D/E/P/S/T/Z etc.) are suppressed — letters become note triggers (FL works the same way).

### D-5: Recording precount metronome (transport, Ctrl+P)
- Existing 1/2/4-bar precount rewritten: precount fires only when **record-arm is on AND playback is starting**, plays exactly **4 beats (1 bar)** at current tempo, then recording engages on bar 1.
- Old 1/2/4-bar selector removed from metronome panel.

### D-6: Riff Machine (Piano Roll, Alt+E)
- Standalone session. Pattern-generator dialog: scale picker, rhythm density slider, octave range, chord/melody mode, generate/regenerate button, accept/cancel.
- Writes notes into the active piano roll on accept. Approximates FL Riff Machine UX.

### D-7: Smaller Piano Roll features bundle (~1 session)
- **M** — toggle keyboard column visibility.
- **Alt+F (Flam)** — for each selected note: insert a grace note at -1/16 length, 60% velocity.
- **Alt+V (Ghost toggle)** — show/hide ghost notes (per D-7a rules).
- **Alt+X (Scale Levels)** — popup with velocity slider + numeric input applied to selection.
- **Alt+Mouse-wheel** — adjust currently-selected control-lane property of note under cursor.
- **Ctrl+Q (Quick Quantize)** — snap to nearest 1/4 note, no dialog.
- **Ctrl+U (Quick Chop)** — split into 4, no dialog. Alt+U keeps existing chop-with-dialog.
- **Ctrl+L (Quick Legato)** — extend each selected note to start of next.
- **Ctrl+Alt+Home** — toggle "resize from left edge" mode.
- **Ctrl+Delete** — remove time-region equal to selection's beat-extent; shift later notes left.
- **Ctrl+Up/Down** — transpose selection ±12 semitones.
- **Ctrl+Left/Right** — shift the time-selection box (not contents) by its own length.
- **Shift+Ctrl+V** — separate clipboard buffer, persists across piano-roll tabs (sibling tabs share it).
- Drop Shift+N (turn-off chord) — no chord groupings exist, removed from spec.

### D-7a: Ghost notes overhaul (all tabs)
*Promoted to its own batch — broken everywhere, not just drums.*

**Per-tab visibility rules:**
- **Layers piano-roll tab** — shows ghost notes from: all other Layers + all Basses + all Drums.
- **Bass piano-roll tab** — shows ghost notes from: all other Basses + all Layers + all Drums.
- **Drum's individual piano-roll tab** (per-drum sub-tab) — shows: all other Drums + all Layers + all Basses.
- **Drum Kit view** — no ghost notes at all.

**Implementation:** Drum ghost notes read directly from each drum's `pattern.drumRolls[i]` (per-drum piano-roll arrays from D1.1), not from the kit grid. Single code path for all tabs.

### D-8: Note Properties dialog + slide/porta DSP fix
- Mirror drum-kit's note-properties popup. Shows: velocity, pan, length (beats), type (Standard/Slide/Portamento), MIDI note. Apply to single or all-selected. Triggered by double-click on note.
- Double right-click on ghost note → switch active tab to ghost note's owning tab.
- **Bundles:** the slide/portamento DSP fix (currently both don't actually affect playback per your #9 note).

### D-9: Export Audio rebuild (broken — fix + UI)
- Single menu item **Export Audio...** (replaces "Export as WAV" / "Export as MP3" submenu).
- Ctrl+R opens this.
- Popup: format dropdown (WAV / MP3 / FLAC), bit depth (16/24/32), sample rate (44.1k/48k/96k), tail seconds, file picker, render button.
- Render path itself is currently broken — investigation + fix included.

### D-10: Undo coverage sweep.** Picks up everything from `Files For Claude/undo_audit_2026-04-26.md` that isn't covered by B-5. Sub-batches:
  - **D-10a** — Wire APVTS → UndoManager on all processors (Harmless / BaySickSynth / BaySickBass / VibePlayer / VibeSynthProcessor). Verifies attachment-driven `beginChangeGesture/endChangeGesture` so drags don't spam undo with 100 entries. Single biggest win — unlocks undo for hundreds of params at once.
  - **D-10b** — `MixerStateAction` wrapping for fader / pan / mute / solo / width / polarity / arm / sends / aux strip add+delete.
  - **D-10c** — `EQBandSnapshotAction` for `ParametricEQDisplay` band drag / right-click param / Reset All.
  - **D-10d** — `DrumKitStateAction` for row mute / solo / lock / reorder / add.
  - **D-10e** — `InstrumentTabAction` for engine pick / lock / polyphony / sound load / patch load / delete / rename on Layer/Bass/Drum tabs.
  - **D-10f** — `PatternAction` for create / rename / delete / clone / color from transport-bar dropdown.
  - **D-10g** — Tail items: Builder row rename, effect rack output gain, routing-edge changes (cable drag).
