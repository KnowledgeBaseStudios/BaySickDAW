## 1. MIXER ARCHITECTURE & TRACK LAYOUT

### Track Types
Implement three categories of Mixer tracks:

- **Insert Tracks** — 500 total. Receive audio input from instrument plugins and external hardware audio inputs. Audio passes through loaded effects, then through integrated track properties (3-band parametric EQ, phase, stereo separation, volume, pan), then routes to the Master or other Insert Tracks.
- **Current Track (C)** — 1 utility track that receives the output of whichever Insert Track is currently selected. Used to host tools like analysis plugins. If FX or EQ levels are changed on this track, they apply to whichever track is currently selected. Display a clear warning.
- **Master Track** — 1 track. All audio routes here by default (unless a track is routed directly to an ASIO output). This is where mastering effects and final output levels are set. Master Track output must be routed to an audio device output or no audio will be heard.

### Docking System
Implement three docks: **Left**, **Middle**, and **Right**, separated by draggable track dividers. Behavior:
- Left and Right docks are fixed (do not scroll).
- Middle dock scrolls; use mouse-wheel over the track name area or the Track Scroll Bar below the Send switches.
- Any Mixer Track can be docked to any dock via right-click → Dock to (Left / Middle / Right).
- Track dividers have a drag handle (three vertical dots) to set the relative height of faders and peak meters independently per dock.

### Layout Modes
Implement 8 view modes from **Compact** to **Extra Large**. Each mode adjusts which controls are visible based on the current horizontal and vertical size of the Mixer window. Extra Large mode shows the effects chain per track inline. In **Alt** view variants, place track names under the Peak Meters instead of above.

The Mixer window must be:
- Resizable by clicking and dragging any edge horizontally or vertically.
- Stretchable both horizontally and vertically, with layout controls adapting accordingly.

## 3. PER-TRACK CONTROLS

Implement all of the following controls on every Insert Track and the Master Track:

### Track Header / Label
- Display track number and name.
- **Middle-click** OR **right-click → Rename / color** (or press F2) to rename and recolor.
- Track labels are part of the selection area (used with Ctrl+Shift for multi-select).

### Track Selection
- **Left-click** on pan or fader control to select a track.
- **Ctrl+Shift + Left-click** on the label/meter area, or left-click and drag across multiple labels/meters, to select multiple tracks.
- Selected tracks show **green faders**.
- Adjusting any fader in a multi-track selection moves all selected faders proportionally.
- **Ctrl+A** selects all tracks.

### Track Reordering
- **Alt+Left / Alt+Right arrow** to move the selected track left or right.
- **Shift+Mouse-wheel** over a track to move it.
- All internal and external audio routing links move with the track.

### Peak Meters
- Display output level in dB.
- Insert Tracks cannot clip (clipping only possible on Master Track or tracks routed to ASIO output).
- Support **Meter Wave View** mode (Alt+W): replace bar meters with scrolling waveform; width = peak level.
- 2-finger tap on meters (multi-touch gesture mode) = multi-track selection.

### Mute Switch
- **Left-click** — Mute/unmute the track.
- **Ctrl+Right-click** — Unmute all tracks.
- **Ctrl+Left-click**, **Alt+Left-click**, or **Right-click → Solo** — Solo/unsolo the track.
- **Shift+Left-click** — Lock/unlock the mute state.
- **Alt+Left-click** — Solo the track AND all tracks routed to and from it.
- Support "Restore previous state after solo" from General Settings: preserves the mute pattern prior to solo.

### Pan Control
- Controls stereo position (left/right) using a **Circular Panning Law** by default (configurable in project settings).
- Pan works by mixing one side of the stereo track into the other; 100% pan = mono-sum of L+R.
- Right-click → Create automation clip / Link to controllers.

### Level Fader
- Volume control applied **post-effects** (post-fader).
- Click **above or below** the fader handle to initiate a smooth level change.
- **Colors:** Grey = default, Green = selected, Orange = armed for recording.
- Adjust multiple faders: select multiple tracks (Ctrl+Shift + click/drag on label/meter area), then move any one fader in the group.
- Right-click → Create automation clip / Link to controller / Edit events.

### Stereo Separation
- Knob with three zones:
  - **Center (default)** — disabled/no effect.
  - **Right (clockwise)** — decrease stereo separation (sum L+R toward mono).
  - **Left (counter-clockwise)** — increase stereo separation.
- Has no effect on mono sources (processes only the L−R difference signal).

### Invert Phase
- Flips the sign of the waveform (positive peaks become negative and vice versa).
- Used to correct phase cancellation from multi-mic recordings or out-of-phase percussion samples.

### Swap Channels
- Swaps Left and Right stereo channels.
- Used to correct cabling errors or match the panning of pre-recorded audio.

### FX Master Switch (per track)
- **Left-click** — Enable/disable all effects on the selected track simultaneously.
- **Right-click** — Open/close the UI for all effects on the track simultaneously.
- Dark-gray and unresponsive when no FX are loaded.
- Responds to multi-track selection: selecting all tracks (Ctrl+A) and clicking any active FX icon enables/disables all FX across all tracks in the project.

### Track Delay
- Accurate time-offset delay for the track (not an audio effect; used for Plugin Delay Compensation).
- **Colors:** Grey = no value set, Orange = automatically set by PDC, Blue = manually set.
- Click the switch to select offset in samples.
- Can be used for fine-tuning time-alignment of audio clips on separate mixer tracks.

### Track Recording Arm Switch
- **Left-click** — Arm the track for recording (turns red when armed).
- **Right-click** — Arm with record-file naming option.
- When armed, all internal or external audio sources routed to the track will be recorded.

### Send / Sidechain Switch
- Present on each track; shows available destination tracks.
- **Left-click** a destination track's Send switch to enable audio routing from the selected (source) track to that destination.
- When activated, the Send switch is replaced by a **Send Level Knob** on the destination track controlling the received signal level.
- **Right-click** — Route as sidechain only (send volume set to 0; audio not audible on destination, only available to sidechain-capable plugins on that track).

## 6. AUDIO INPUT & OUTPUT (External Routing)

Each Mixer Track has one stereo Input selector and one stereo Output selector.

### Input Selector
- Shows available hardware audio inputs from the ASIO audio device.
- **(none)** = no external input selected.
- Top of the list combines pairs of inputs for **stereo input**.
- Lower part of the list shows **mono inputs** individually.
- **Right-click Input menu** → Auto map: automatically routes available device inputs to Mixer Insert tracks starting from the selected track.
- **Right-click → Reset mapping**: removes all selected input devices (excluding Master output).
- Recording Pickup Selector: click the icon in front of the Input selector to choose recording scope.
- ASIO driver required for any external input/output options to appear.

### Output Selector
- Shows available ASIO hardware outputs.
- **(none)** = no external output selected (except Master, which defaults to the device's main outputs).
- The Master Track's output MUST be set or no audio will be heard from FL Studio.
- Multiple tracks can send to the same output.
- Use cases: headphone monitoring sub-mixes, surround sound sub-mixes, live performance monitoring.

### Surround Sound
- Support routing to surround sound configurations:
  - **5.1**: 3 Mixer Track outputs (Front L/R, Rear L/R, Center/Sub L/R).
  - **7.1**: 4 Mixer Track outputs (Front L/R, Side L/R, Rear L/R, Center/Sub L/R).
- Provide surround icons for labeling tracks.

### Parallel Routing
- Input and Output selectors work in parallel with internal routing. Any track can simultaneously receive external and internal audio, and output to both the Master and a hardware output.

## 7. INTERNAL MIXER TRACK ROUTING & SIDECHAINING

### Send Routing (Post-Fader, Default)
- Any Insert Track can be routed (sent) to any number of other Mixer Tracks.
- **To create a send:** Select the source track → click the Send switch on the destination track. A Send Level Knob replaces the Send switch on the destination.
- **To remove a send:** Click the Deselect Switch above the Send Level Knob. Alternatively, set the send volume to 0 to keep the link but silence the audio.
- Send level knob controls the signal level received from the source.

### Pre-Fader Sends
- Default sends are post-fader (taken after the fader).
- To create a pre-fader send: use the Fruity Send plugin loaded in Effects Slot 1 (earliest in chain) to extract audio before the fader.

### Sidechain Sends
- A sidechain send routes audio from one track to another **without the audio being heard** on the destination track. It is available only to plugins with sidechain inputs loaded on the destination.
- **All audio sends are also sidechain sends** (both paths always exist).
- A send becomes sidechain-only when the Send Level Knob is set to 0%.
- Sidechain sends shown as low-contrast (grayed-out) cable icons in the routing display.
- **To create sidechain only:** Right-click the Deselect Switch → "Sidechain only to this track" (sets send volume to 0 automatically).
- Sidechain source track remains routed to Master; deselect its master send if unwanted.
- Sidechain direction depends on the plugin (some receive from another track, some send to another track).
- Available sidechain tracks are labeled by track name when a plugin's sidechain selector is right-clicked.

### Routing Iconography
Implement visual routing indicators at the bottom of the Mixer:

| Icon State | Meaning |
|---|---|
| Downward green arrow | Selected track is sending audio to other tracks |
| Up-arrow (available) | Track is available as a send destination; clicking creates the send |
| Grayed-out cable | Sidechain send (volume at minimum; audio available to sidechain plugins only) |
| Grayed-out send switch | This track is a source routed to the selected track (unavailable as destination to prevent feedback loops) |
| Small up-arrows on a track | Another track is sending audio to this track |

Audio cable routing must be shown visually, including cables that cross the Master track divider (shown dropping off the bottom rather than making a direct visual connection).

### Multiple Track Routing
- Hold Ctrl+Shift and Left-click (or click+drag) to select all tracks involved, including the target.
- Still holding Ctrl+Shift, Right-click the target track — it highlights slightly lighter than others.
- Context menu shows "this track" as the target for routing actions.
- Track routing options available in the right-click menu under **Track Routing >**.

## 8. INSTRUMENT CHANNEL TO MIXER TRACK ROUTING

Support all of the following routing methods from the Channel Rack to Mixer Tracks:

### Method 1: Channel Rack Routing Selector
- Display a Mixer Track Routing selector in front of each Channel Rack instrument button (Alt+M to show/hide).
- If hidden: left-click the channel button to open the instrument, then click the Channel Settings icon.
- **Auto-assign**: click the 'TRACK' label below the routing selector — assigns to the first free Mixer Track and names it.

### Method 2: Quick Link (Keyboard Shortcuts)
- From Channel Rack: select Channel Selector(s) for channels to route, then select destination Mixer Track and press **Ctrl+L** — routes all selected channels to that track.
- **Ctrl+Shift+L** — sequentially routes selected channels to consecutive Mixer Tracks starting from the selected track.

### Method 3: Drag and Drop
- Drag plugin preset from Browser or Plugin Picker (F8) onto a **Playlist Track header** → creates Instrument Track link (Channel Rack instrument ↔ Playlist Track ↔ Mixer Track).
- Drag and drop instruments from Browser Plugin Database (Shift+F8) or Plugin Picker (F8) directly onto a Mixer Track → auto-names the Mixer Track to match the instrument.

### Method 4: Right-Click on Mixer Track
- Right-click Mixer Track → Channel routing → **Route selected channels to this track** (Ctrl+L).
- Right-click Mixer Track → Channel routing → **Route selected channels starting from this track** (Ctrl+Shift+L).
