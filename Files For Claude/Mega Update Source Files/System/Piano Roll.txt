## 1. CORE PIANO ROLL ARCHITECTURE

### Display Fundamentals
- Notes are displayed as horizontal bars on a 2D grid.
- **Vertical axis** = pitch (low at bottom, high at top).
- **Horizontal axis** = time (bars displayed along the top ruler; numbers represent bars/groups of beats).
- **Slide notes** displayed as horizontal bars with a small triangle drawn at the start of the note.
- **Muted notes** displayed distinctly from active notes.
- The grid resolution is user-selectable and zoomable.
- Middle-mouse-button + drag scrolls both vertically and horizontally simultaneously.

### Target Channel
- A drop-down menu in the title bar selects which Channel Rack instrument channel is being edited.
- Channels with notes in the currently selected Pattern display a tick/checkmark next to their name.
- Mouse-wheel while hovering over the selector cycles through Channels that have notes.
- Ctrl+Mouse-wheel shows both used and unused Channels.
- **Auto locate**: when Patterns are changed, the Piano roll auto-selects the first Channel that has notes.
- Right-click the Target Channel selector to open the instrument's interface.

### Opening from the Playlist
- If the Playlist Menu option "Edit patterns in > Piano roll" is set, double-clicking a Pattern Clip opens the Piano roll for that Pattern Clip.
- Where you click on the Pattern Clip determines where the Piano roll scrolls to horizontally when opened.

### Pattern Mode & Time Markers
- In Pattern Mode, the add Time Marker function places a marker where the Playhead is located.
- Right-click the Time Marker to select its type.
- When set to type **Pattern length**, right-clicking defines the length of the currently selected Pattern.

## 5. NOTE OPERATIONS

### Adding Notes
- In Draw mode: left-click to add a note at the default length (equal to the last touched note). Hold Left-Shift + left-click+drag to draw a note of a specific length.
- In Paint mode: left-click to add a single note; click+drag horizontally to add multiple notes. Notes are added **monophonically** by default (replacing any overlapping notes). Hold Shift to bypass monophonic mode and allow chords.
- In Draw or Paint mode: left-click in the grid adds a note; the default note length equals the last touched note.

### Deleting Notes
- Right-click a note in Draw or Paint mode to erase it.
- In Delete mode: left-click or left-click+drag to delete.
- Right-click+drag in Draw/Paint mode deletes multiple notes.

### Selecting Notes
Implement all selection methods:

| Method | Behavior |
|---|---|
| Ctrl+click on a note | Select it |
| Ctrl+drag rectangle | Select all notes within the rectangle |
| Ctrl+Shift+drag | Add notes to existing selection |
| Ctrl+Shift+click | Toggle individual note in/out of selection |
| Ctrl+click on empty space | Deselect all |

| Select tool (E) | Click or drag rectangle to select |

### Moving Notes
- Left-click a note and drag horizontally (timing) or vertically (pitch).
- Snap setting affects horizontal movement; hold Alt to override.
- **Pitch lock (vertical lock)**: click the note first, THEN hold Shift and drag horizontally — note pitch is locked, only timing moves.
- **Timing lock (horizontal lock)**: click the note first, THEN hold Ctrl and drag vertically — note timing is locked, only pitch moves.

### Nudging Notes
- **Snap units**: select note(s), hold Shift + press arrow keys. Bump size follows current snap setting.
- **Pixel units**: hold Alt + press arrow keys. Bump size follows current zoom level.
- **Mouse-wheel horizontal nudge**: Shift+Alt+Mouse-wheel while hovering over a note/selection. With the Piano Roll Menu Edit option "Nudge notes with the mouse-wheel" enabled, Shift alone + mouse-wheel works.

### Resizing Notes
- Move cursor to the **right edge** of a note until a double-headed arrow appears; left-click+drag to resize from the end.
- Move cursor to the **left edge** of a note; left-click+drag to resize from the start. Requires "Allow resizing from left" option in Piano Roll Menu > Edit.
- Resize affects single notes or entire selections.
- Snap setting affects resize increments.

### Copying and Pasting Notes
- **Copy by drag**: make a selection → release mouse and Ctrl → hold Shift → click+drag selection to new position.
- **Ctrl+C / Ctrl+V**: copy selection, scroll to new position or pattern, paste.
- **Duplicate (Ctrl+B)**: duplicates the selection (or all notes if nothing selected) to the right of the original. Time-line selection sets the repeat interval; note selection sets what is duplicated — these are independent. Notes outside the time-line selection can be duplicated according to the time-line interval.

- **Shift+G** — group selected notes. Any action on one note in the group affects all others (move, resize, delete, etc.).
- Any number of groups may be created.
- Activate/deactivate grouping globally with the Note/Pattern Grouping switch on the Toolbar.

### Stretch / Compress Selection
- After selecting notes, a **Stretch Handle** appears; drag it to stretch the entire selection (adjusting both note lengths and sequence duration).
- Hold Alt to apply snap settings during stretch.
- **Alternative**: hold Right-Shift + click+drag on the right side of any note in the selection.
- Alt+Right-Shift stretches in 25% increments.

### Resize Chords & Splits
- Hold Left-Shift, then click+drag on the slice point or right side of a chord to resize.

### Slicing Notes
- In Slice mode (C): left-click+drag to define a cut line; release to split all notes at their intersection with the cut line.
- Shift = slice without dragging.
- Ctrl+G glues a selection of touching notes.

### Click-and-Hold Functions (requires General Settings > Click-and-hold functions in Piano Roll enabled)
- **Copy note**: hold on an existing note to copy it.
- **Cycle slide/porta**: click+hold when adding a note to cycle through slide and portamento modes.
- **Glue notes**: place cursor between two neighboring notes so the resize cursor appears, then click+hold to glue them.

### Mouse-Wheel Velocity
- Hold Alt+Mouse-wheel while hovering over a note to change its velocity (currently selected note property).
- Hovering over one note in a selection with the same technique changes that note's property.
- Hold Ctrl+Alt+Mouse-wheel for fine adjustment.

### Mouse-Wheel Tool Switching
- Hold right-click + roll mouse-wheel to cycle through tools.

### Playback / Scrub Tool
- In Play Selected mode (Y): click+drag horizontally to scrub-play notes at variable speed.
- In Draw mode: hold Alt+Right-click to temporarily activate scrub playback.

### Play Truncated Notes

### Merging Scores Across Patterns
- Place Pattern Clips in the Playlist with the target Pattern at the top.
- Select all clips to merge.
- Use Playlist Menu > Edit > Merge pattern clips to merge selected clips into the uppermost Clip.

## 8. SLIDES & PORTAMENTO

### How Slide Notes Work
- Slide notes **must overlap** the note(s) they slide; a standalone slide note produces no sound.
- Overlap length sets the slide time.
- When the slide note is reached, the pitch of the overlapped note begins sliding toward the slide note's pitch, reaching it at the end of the slide note event.
- If the note being slid ends before the slide pitch is reached, the slide terminates prematurely.
- **For chords**: the topmost note is the reference for the pitch offset; all notes in the chord slide so the topmost note reaches the slide note's pitch; all notes move the same interval. After the slide event ends, notes remain offset from their original pitch.
- **Color group isolation**: slide notes only affect notes of the same color group. Up to 16 simultaneous independent slides are possible (one per color group).
- Slide events have all standard note properties (velocity, pan, cutoff, resonance, etc.). During a slide, all note properties move toward those set in the slide note.
- Slides produce no sound on their own but allow preview when created/moved.

### How Portamento Notes Work
- Portamento only applies to the pitch transition from one note to the next (a fast, brief slide at note transitions).
- Most audible with larger pitch intervals.
- The portamento flag is set on the **receiving** note (the note to receive the effect).
- Only works with native FL Studio instruments, not VST/AU.
- To slide VST instruments, automate the channel pitch knob.
- Channel Settings > Misc > Polyphony > SLIDE interacts with Portamento notes.
- Channel Settings > Misc > Time > GATE interacts with both Portamento and Slide notes.

## 9. TIME SIGNATURES & KEY SIGNATURES

### Time Signatures
- Default project time signature set in Project General Settings.
- Support **custom and multiple time signatures per Pattern**.
- Since Patterns exist independently of the Playlist time signature, multiple time signatures can coexist at any point in the Playlist (polyrhythm by stacking Patterns with different time signatures).
- Time signatures are a visual grid helper only; they do not technically affect notes, only the grid behind them changes (except for the downbeat on the Metronome).
- Changing the time signature for any channel affects **all channels** in the Pattern; use Pattern Clip Menu "Make unique" to isolate.

**Operations:**
- **Set a custom time signature**: place the playhead at the desired point → hold Shift+Alt+T to open the Time Signature tool.
- **Set a time signature range**: make a time selection → hold Shift+Alt+T. The time signature reverts to the project default at the end of the selection.
- **Set a time signature based on Playlist Clip location**: open the Clip Menu and select "Use current time signature".
- **Move time signatures**: drag the Time Marker.
- **Pattern length marker**: right-click a Time Marker set to "Pattern length" type to define the length of the currently selected Pattern.

### Key Signatures / Scales
- **Snap to Scale** (see toolbar): active scale highlights notes in the Piano Roll grid background.
- Right-click the Snap to Scale icon to choose **Tonic note** (12 chromatic options) and **Scale** (full list of named scales including Major/Ionian, Minor/Aeolian, and all others in the scale database).
- **Snap incoming MIDI**: option in the Snap to Scale right-click menu; routes incoming controller MIDI notes to the nearest in-scale note in real time.
- **Scale Markers**: can be placed in the Piano Roll timeline; the Automatic chord mode reads from these as well as the Snap to Scale setting.
- When no scale is specified, the Automatic Chord mode infers from existing notes or picks randomly.
