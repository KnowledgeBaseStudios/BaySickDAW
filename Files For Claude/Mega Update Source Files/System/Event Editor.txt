## 1. CORE EVENT EDITOR ARCHITECTURE

### What Event Automation Is
- The Event Editor holds automation data that moves linked controls according to curves recorded, hand-drawn, or set manually.
- Event Automation is **bound to a specific Pattern/Pattern Clip** — this is the key distinction from Automation Clips, which exist as independent generator plugins not bound to any Pattern.
- Event data can be recorded from live controller movements OR drawn by hand in the Event Editor.
- Automation Clips can only be edited, not recorded into; Event data can be both recorded and edited.
- A single Pattern may contain **multiple independent Event Automation data-sets** (one per target control); use the Target menu to switch between them. There is no limit on the number of Event Automation data-sets per Pattern.
- Event Automation may link to controls on the DAW interface itself or in plugins (both native and external VST/AU).

### Difference from Automation Clips
- Event Automation is pattern-bound; Automation Clips are not.
- Event data can be converted to an Automation Clip via **Menu > Edit > Turn into Automation Clip**.
- Once converted to an Automation Clip, it appears as an "Internal Controller" link option in the "Link to controller" right-click dialog on automatable controls, and also in the Browser > Current project > Remote control list.

### Display
- The Event Editor graph shows **time on the horizontal axis** (measured in bars) and **automation values on the vertical axis** (0 to 100%).
- Events are displayed as **vertical lines** whose height represents the value of the event.
- The Event Editor window can display **only one event data-set at a time**.
- Only data from the **currently selected Pattern** is shown. Change the Pattern via the Toolbar Pattern Selector or the Playlist Picker Panel.
- Time segments of the grid are set by the window's snap parameter. Selecting "Main" implements the global snap value from the Global Snap Panel.

## 3. WORKING WITH EVENT DATA

### Opening the Event Editor
Two methods:
1. Select a Pattern → right-click the target control on the DAW interface or plugin → select "**Edit events**". If automation data was recorded for this control it is displayed; if none exists the editor opens empty for manual drawing.
2. Browser > Current project > Patterns > [Pattern name] → left-click an automation target to open the Event Editor directly.

To open in a new window (instead of reusing the existing one): select **Edit Events in New Window**.

### Creating Events
- Switch to **Draw Mode** (P) or **Paint Mode** (B).
- **Left-click** in the Event Graph Area to create a single event.
- **Left-click+drag** to draw a freehand curve of events.
- **Right-click+drag** in the grid to draw straight lines of events.
- Draw Mode and Paint Mode are functionally identical **except** Paint Mode ignores the current snap settings, allowing smooth curve drawing without changing snap preferences.

### Interpolating Events
- Switch to **Interpolate Mode** (I).
- Left-click+drag to select the target events; they are marked blue.
- On mouse release, selected events are redrawn using **linear interpolation**.
- Right-click+drag in Interpolate Mode uses **spline interpolation** instead.

### Erasing Events
- Switch to **Erase Mode** (D).
- Left-click+drag to select events to be removed; they are marked red.
- Events are deleted when the mouse button is released.
- Erased events reset to the value at the **start** of the selected range, not to zero.

### Selecting Events
- In **any** mode (draw, erase, interpolate): double-click OR Ctrl+click the time ruler and drag to select a time range.
- In **Select Mode**: single left-click+drag to select a time range.
- Selections are used for: cutting, copying, LFO tool operations, and other range-based edits.

### Select Previous / Select Next
- **Select Previous** (Ctrl+Left) — shifts the selection backward so that the start of the new selection matches the previous selection's end. E.g., if one bar is selected, the previous bar becomes selected.
- **Select Next** (Ctrl+Right) — shifts the selection forward so that the end of the new selection matches the previous selection's start. E.g., if one bar is selected, the next bar becomes selected.

### Insert/Delete Space
- **Insert Space** (Ctrl+Ins) — creates empty space matching the current selection by shifting all following events forward.
- **Delete Space** (Ctrl+Del) — erases all events in the current selection and shifts all following events backward to close the gap.

### Insert Current Controller Value
- **Ctrl+I** — inserts the **current live value** of the corresponding automated control into the Event Editor.
- If a time slice is selected, the current value is inserted at the **beginning** of the selection.
- Initializes the Event Editor with a real-world starting value without manually drawing it.

## 7. ACCESS POINTS — WHERE EVENT DATA IS DISPLAYED AND EDITED

Implement all three access methods:

### From the Event Editor (Standalone)
1. Select a Pattern → right-click the target control → "Edit events" → Event Editor opens showing that data.
2. Browser > Current project > Patterns > [Pattern name] → left-click an automation target file → Event Editor opens.
3. "Edit Events in New Window" option to open a second concurrent Event Editor window.

### From the Piano Roll (Integrated Lower Panel)
- Event Automation data can be displayed and edited in the **lower panel** of the Piano Roll.
- Select a Pattern containing automation data → select the Event Automation target from the Target Control menu in the Piano Roll toolbar.
- The lower panel displays events as vertical lollipop lines (same visual style as note properties).
- The splitter handle between the upper note grid and lower event panel is resizable (left-click+drag); right-click resets to default.

### From the Playlist
- Event Automation data is shown as **shading inside Pattern Clips** in the Playlist.
- Clicking into a Pattern Clip that contains Event Automation and opening the Piano Roll or Event Editor will show that data.

## 10. CONVERTING EVENT DATA TO AUTOMATION CLIPS

- Use **Menu > Edit > Turn into Automation Clip**.
- Opens a **Sensitivity** pop-up with a slider to control how many control points are used to represent the Event data in the new Automation Clip.
- Fewer points recommended for easier subsequent editing.
- When conversion exceeds 40 ms, switches to "compute on mouse up" mode; mouse-wheel over the slider provides better interactive control.
- After conversion, the new Automation Clip:
  - Appears in the Playlist Clip Track area.
  - Appears as an **Internal Controller** option in the "Link to controller" right-click dialog on any automatable control.
  - Appears in the Browser > Current project > Remote control list.

---

## 11. RECORDING AUTOMATION INTO THE EVENT EDITOR

- All recorded automation (from live controller movements during playback) is saved as Event Data in the currently selected Pattern at the time of recording.
- The selected Pattern during recording holds all recorded automation.
- Recorded automation appears in the Event Editor for the corresponding Pattern and target control.
- Recorded data can subsequently be manually edited and refined in the Event Editor.
- The Global Snap setting can quantize live MIDI input recording.
