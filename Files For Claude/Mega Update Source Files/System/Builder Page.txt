## 1. CORE PLAYLIST ARCHITECTURE

### Clip Types
Support three distinct clip types that can coexist on any track in any combination:
- **Pattern Clips** — hold MIDI note data and/or event automation data. Display as a layered/combined view when both are present.
- **Audio Clips** — hold audio recordings.
- **Automation Clips** — hold parameter automation envelope data.

Any clip type may be placed on any playlist track. Clips of different types may overlap on the same track with transparency. Tracks are NOT bound to mixer tracks — instrument channel-to-mixer routing determines audio routing, not the playlist track.

### Track Mode (optional structured workflow)
Support a "Track Mode" that links an Instrument Channel ↔ Playlist Track ↔ Mixer Track as a named group. Dropping a plugin or audio file on a track header creates this link. Track modes:
- **Unassigned** — no associations; free workflow.
- **Instrument Track** — linked to a Channel Rack instrument and a Mixer track. Double-clicking the track header opens the plugin. Deleting the channel or playlist track offers to delete everything in the group.
- **Audio Track** — linked to a Mixer track for recording and audio clip routing. The (A) icon turns red when armed for recording; show on-track controls for: select audio input, recording location & monitor options, arm recording.

Name/color/icon changes ripple across all members of a Track Mode group (excluding the Pattern).

Implement a local snap selector with these options:

- **Line** — snaps to nearest grid line (resolution changes with zoom)

Hold **Alt+Q** (Quantize) to reset grid offset of the last touched clip.

Notes:
1. Scroll speed slows when snap is set to anything other than Line.
2. Main snap defers to Global Snap panel.

## 5. CLIP EDITING OPERATIONS

Implement all of the following universal clip editing methods:

### Copy/Paste/Duplicate
- Copy/Paste: Ctrl+C / Ctrl+V; scroll Playlist so paste start bar is at left edge
- Copy by dragging: select → release → hold Shift → click+drag selection
- Duplicate: Ctrl+B (duplicates selection or all clips to the right; time-line selection defines interval; clip selection defines what is duplicated)

### Slicing
- Slice tool: click+hold+drag vertically through clips
- No-drag slicing: in Slice mode, hold Right-Shift, click+hold, position horizontally, release
- Slicing in Paint/Draw mode: Alt+Right-Shift

### Resizing & Slip Editing
- In Draw/Paint mode: Shift+drag on clip start/end to resize (data does not move)
- Slip Edit tool: left-click+drag inside clip to slide content left/right

### Rescale Clip Placement
- Make selection → Right-Shift+click right side of rightmost clip → drag; Alt = snap to 25% increments

### Other Operations
- Swap clip: open Clip Menu → Select source channel → pick alternative (hold Shift to preserve start/end)
- Edit clip channel settings: open Clip Menu → Channel Settings, or double-click title bar
- Group clips: Shift+G; grouping causes all in group to move/select/delete together
- Ungroup: Alt+G
- Group on/off switch in toolbar shortcut icons
- Move clips vertically: select → Shift+Up/Down arrow
- Audition: Playback tool + click clip, or Alt+Right-click on clip, or Clip Menu → Preview
- Clone (Make Unique): Clip Menu → Make Unique, or Shift+V+left-click+drag

## 13. AUTOMATION CLIPS — FULL IMPLEMENTATION

### Creating Automation Clips
Support all creation methods:
1. Right-click any native FL Studio control → "Create automation clip"
2. Last tweaked (VST/AU): tweak control → Tools Menu → Last tweaked → Create automation clip
3. Current project (VST/AU): Browser → Current project → Generator/Effects → right-click parameter → Create automation clip
4. Add menu → Automation from last tweaked parameter
5. Convert from Event Data: Event Editor → Edit → Turn into automation clip
6. Audio Clips: Clip Menu → Automate → Volume or Pan

**Time range behavior:** If a time range is pre-selected in the Playlist, the Automation Clip is restricted to that range. Otherwise it spans the full song length.

**Placement:** In Instrument Track mode, placed as a sub-track of the parent. Otherwise, auto-placed on the highest empty visible Playlist track.

### Deleting Automation Clips
- Delete the Automation Clip Channel in the Channel Rack OR delete from Picker Panel
- Deleting from the Playlist only removes the instance, not the Channel
- Initialized controls: save the current control value when clip is created; the control returns to this value on playback start
  - Remove initialization: Browser → Current project → Patterns → Initialized controls → right-click → Delete event; OR set control to desired level → right-click → "Init song with this position"
  - Prevent initialization: General settings → "Don't initialize controls automatically"

### Automation Clip Controls in Playlist

**Clip Focus Tab:**
- **Step mode**: Left-click+drag creates freehand curve with a new control point per step (snap-dependent); Shift+drag = pulse lines (straight vertical/horizontal only); each new segment uses the last set tension
- **Slide mode**: dragging a control point slides all following points maintaining relative distances; deselected = move control points horizontally only without changing clip length; Shift+click before dragging locks vertical value

**Control Point Operations:**
- Add: Right-click+hold+drag to reposition; Shift = lock vertical; Ctrl = lock horizontal; Alt = override snap; Shift+Right-click = add without disturbing existing level; if snap on: Alt+Shift+Right-click
- Copy/Paste value: right-click point → Copy value; right-click destination → Paste value
- Delete: right-click → Delete (Step mode must be off) OR Right-Alt+Left-click
- Move: Left-click+drag; Shift = lock vertical; Ctrl = lock horizontal; Alt = override snap
- Set precise value: right-click node → "Type in value..." (0 to 1)
- Change curve tension: left-click tension handle + move up/down; Ctrl = fine adjustment; right-click tension handle = reset
- Change curve type (right-click rightmost control point of segment):
  - Single curve (default, straight or curved per tension)
  - Double curve (smooth S-curve)
  - Alt single curve (asymmetric smooth S-curve)
  - Alt double curve (asymmetric linear/accelerating/decelerating)
  - Hold (single steps between points)
  - Stairs (multiple steps; tension handle adjusts step frequency)
  - Smooth stairs (smooth steps; tension handle adjusts frequency)
  - Pulse (square wave; tension = frequency)
  - Wave (sine wave; tension = frequency)
  - Half sine (one half sine wave)
  - Smooth (smooth S-curve join)

**Change clip length:** Drag the last control point. Clips created from a Playlist selection span that selection; otherwise span the full song length.

**Clone/Copy:** Clip Menu → Make unique (new clip is unlinked from original targets)

**Restrict automation range:** MAX and MIN knobs on Automation Clip Channel settings (Playlist display unchanged)

**Slicing:** Alt+Right-Shift to slice; slip editing (Shift+S) accesses data outside visible window after slice; Clip Menu → Make unique converts slice to independent clip

**Hint bar:** Displays control point and tension handle values while moving

**Triggering:** Automation Clips can be triggered by Piano roll, Step Sequencer, or live MIDI controller. Clip automates while note is held. Does not need to be placed in Playlist to be effective if triggered by note data.

### Automation Clip Channel Settings Editor
Open by double-clicking Automation Clip in Playlist (auto-locates to click position). Implement:
- **Zoom out**: Home key or Magnifying Glass icon
- **Control Point Selection**: Left-click = single; Ctrl+click+drag = multi; Shift+Ctrl+click+drag = add to selection; Middle-click = deselect single; Left-click on background = deselect all

**Options Menu (Automation Editor & LFO):**
- Copy/Paste state
- Flip vertically
- Scale levels (Scale Level tool)
- Normalize levels (highest/lowest reaches ±100%)
- Decimate points (reduce number of control points)
- Filter (Envelope Filter tool)
- Smooth up (Smooth Up tool)
- Smooth up abrupt changes
- Turn all points smooth
- Create sequence (Envelope Sequencer)
- Analyze audio file (creates envelope from audio volume amplitude profile; supports drag-and-drop of audio file)

**Target Links Panel** (icons left to right: Add, Delete, Edit, Locate, Animate):
- Add: click [+], tweak any number of targets, click [+] again to stop
- Delete: remove selected target
- Edit: open Remote Control settings (change link options)
- Locate: open target window or plugin
- Animate: move linked control to aid in finding it
- Convert to events: convert Automation Clip data to Event Data for selected Pattern (Automation Clip remains intact and linked)
- Select in the Playlist: selects this Automation Clip in the Playlist

**Settings Knobs/Controls:**
- **Min**: minimum output value (scaling factor)
- **Max**: maximum output value (scaling factor)
- **Time**: playback speed multiplier (knob + number window for multiplier)
- **LFO Switch**: enables LFO mode; shows LFO preview inside Playlist clips; does NOT erase main automation envelope
- **SPD (Speed)**: LFO speed
- **TENS (Tension)**: LFO shape tension (morph: square pulse → sine → triangle → pulse)
- **AK (Shape Skew)**: skews LFO shape (triangle + skew = saw or reverse saw)
- **NW (Pulse Width)**: LFO pulse width
- **LVL (Level)**: LFO amplitude; center position = 0/disabled; left = negative amplitude (inverted); right = positive amplitude
- **Multiply switch**: when enabled, LFO multiplies main envelope (useful for unipolar parameters like cutoff, volume); when disabled, LFO adds to envelope (useful for bipolar parameters like pan)
