Page Rules
*Pages are what populates the tabs
*When opening a new tab with the + button you will be prompted to select a Layers, Bass or Drums Page
*All sound pages (Layers, Bass or Drums) will have 3 tabs for the page itself, first tab being the selected method of sound creation (Sound Tab), the second tab being the piano roll for that page (Piano Roll Tab) and the third being an EQ effect for that page (EQ Tab)
*For Layers and Bass pages once a selection has been made in the drop down it cannot be changed and a new tab will need to be created to use a different method in the drop down(this is to reduce drain on the system as once a page has been selected we need to make sure that changes stay in place if the change tabs or save the file)

Layers Page
*Layers page opens to blank screen with a drop down
*Layers drop down selections are "Harmless" and "VibePlayer"
*When the layers page drop down is chosen 3 tabs will appear for Sound, Piano Roll and EQ with the Sound tab being filled out with the selected player

Bass Page
*Bass page opens to blank screen with a drop down
*Bass drop down selections are "Harmless", "VibePlayer" and "808/909"
*When the bass page drop down is chosen 3 tabs will appear for Sound, Piano Roll and EQ with the Sound tab being filled out with the selected player

Drum Page
*Drum page only has a piano roll tab with 14 dropdowns for selecting instruments to the left of 14 piano roll keys they are associated with
