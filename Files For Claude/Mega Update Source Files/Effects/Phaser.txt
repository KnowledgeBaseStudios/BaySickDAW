2. Parameters
Frequency Range: Boolean or Enum (Small / Large). Dictates the maximum speed of the LFO.

Sweep Frequency: Float. The speed of the LFO. If Frequency Range is Small, this ranges from 0.0 to 2.0 Hz. If Large, it ranges from 0.0 to 10.0 Hz.

Min Depth / Max Depth: Floats (in Hz). These define the lower and upper frequency boundaries that the LFO will sweep the all-pass filters between.

Stereo: Float from 0 to 360 degrees. Controls the phase offset between the Left and Right channel LFOs (0 = perfect sync, 180 = complete opposite).

Stages: Integer from 1 to 24 (The documentation states up to 23, but you can round to 24 for standard memory allocation). This dynamically sets how many all-pass filters are active in the chain.

Feedback: Float from 0.0 to 1.0 (or >1.0 if safe clipping is implemented). How much of the processed signal is sent back to the input of the all-pass cascade.

Dry/Wet: Float from 0.0 to 100.0%. Mixes the original signal with the phase-shifted signal.

Out-Gain: Float (in dB). A final gain stage to boost the output level.

LFO Generation:

Generate the LFO values for the current sample/block based on the Sweep Frequency.

Calculate the Left and Right channel LFO values using the Stereo phase offset.

Map the normalized LFO values to actual frequency values (Hz) bounded by Min Depth and Max Depth.

Filter Cascade & Feedback Loop:

For each channel, sum the incoming audio with the feedback signal from the previous sample block (multiplied by the Feedback amount).

Pass this summed signal through a cascade of all-pass filters. The number of active filters in this cascade is determined by the Stages parameter.

Update the center frequency of all active all-pass filters using the mapped LFO frequency calculated in step 1.

Store the output of the final active stage to use as the feedback signal for the next sample.

Mix & Output:

Mix the processed phase-shifted audio with the dry audio according to the Dry/Wet parameter.

Apply the Out-Gain multiplier to the final stereo signal.
