2. Parameters
Processing Mode: Enum (Stereo, Mid Only, Side Only). Determines how the input is encoded before entering the reverb engine.

Low Cut (L.CUT): Float (Hz). High-pass filter cutoff for the input signal.

High Cut (H.CUT): Float (Hz). Low-pass filter cutoff for the input signal.

Predelay: Float (ms). Time before the first reflection.

Tempo Sync: Boolean. If true, Predelay snaps to musical subdivisions based on host BPM.

Room Size (SIZE): Float. Scales the internal delay line lengths of the reverb network.

Diffusion (DIFF): Float. Controls the density of the reflections (all-pass filter coefficients).

Decay (DEC): Float (seconds). The RT60 time (time to decay 60dB) for the main reverb tail.

Bass Multiplier (BASS): Float. A multiplier for the decay time of frequencies below the Crossover point.

Bass Crossover (CROSS): Float (Hz). The frequency split point for the Bass Multiplier.

High Damping (DAMP): Float (Hz or coefficient). Rate at which high frequencies decay in the reverb tail. Include a "Bypass" boolean for this.

Early Reflection (ER): Float (dB or %). Level of the initial reflections.

Stereo Separation (SEP): Float (0% to 200%). Width of the wet signal (0 = mono, 100 = original width, >100 = widened).

Dry / Wet Levels: Floats (dB or %).
