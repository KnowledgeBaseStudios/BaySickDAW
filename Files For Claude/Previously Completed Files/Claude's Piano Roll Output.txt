Phase 2 checklist:
* Draw tool (P): Click empty area ? draws note; drag right edge ? resizes; click note ? moves it; Ctrl+click ? add/remove from selection; right-click ? erases
* Select tool (E): Drag empty area ? marquee rectangle selects notes; click note ? selects it; Shift+click ? add to selection; drag selected notes ? moves them; drag right edge ? resizes
* Delete tool (D): Click/drag ? erases notes
* Mute tool (T): Click note ? toggles muted (greyed out rendering)
* Slice tool (C): Drag a line across notes ? splits them at the cut point (red line visible during drag)
* Zoom tool (Z): Drag yellow rectangle ? zooms to that beat range; right-click ? toggle back to previous zoom
* Axis locking: While moving notes, hold Shift ? pitch locked (horizontal only); hold Ctrl ? time locked (vertical only)
* Alt+mousewheel: While hovering a note ? changes its velocity (affects whole selection if note is selected)
* Ctrl+mousewheel: Horizontal zoom in/out
* Right-click+mousewheel: Cycles through tool modes
* Shift+arrows: Nudges selection by one snap unit
* Alt+arrows: Nudges selection by 1 pixel
* Ctrl+A: Select all; Ctrl+Z/Y: Undo/Redo; Ctrl+C/V: Copy/Paste; Ctrl+B: Duplicate
Scale highlighting:
* In any layer's piano roll, find the Scale button in toolbar row 2 — click it to toggle on
* Set Root = C, Scale = Major — the grid rows for C D E F G A B should glow teal/dark green; all black keys (non-scale) stay dark
* Change to Minor or Pentatonic Min to see a different pattern of highlighted rows
Snap-to-scale:
* With Scale on, draw new notes — they'll lock to scale rows even if you click between them
* Move existing notes vertically — they snap to in-scale pitches only
* Shift+Up/Down to nudge — steps to the next scale degree instead of one semitone at a time (e.g. C?D skips C# in Major)
Stamp (chord) tool:
* Click the Stamp button in row 1 (or press no key shortcut yet — just click the button)
* Hover over the grid — you'll see a ghost chord preview following the mouse
* Click anywhere to stamp the chord at that beat+pitch position
* Change Chord Type dropdown (Major, Minor, Sus4, Dom 7, etc.) and stamp different chords
* With Scale also active, the root note snaps to the nearest in-scale pitch before stamping
RMB+wheel — now cycles through all 8 tools including Stamp.

Ghost Notes:
* Go to Layers page, draw some notes on Layer 1 (Sequence sub-tab)
* Switch to Layer 2 — you should see Layer 1's notes as faint blue-gray ghost bars behind the empty grid
* Ghost notes are read-only (you can't click them)
Slide / Portamento visuals:
* Draw a note, then press S — the note gets a small white right-pointing triangle on its right end (Slide type)
* Press S again — the triangle is replaced by a small orange arc on the left end (Portamento type)
* Press S once more ? back to Standard (no indicator)
* With nothing selected, press S — sets the "new note type" mode so the next note you draw comes out as Slide or Portamento
Note Grouping:
* Select several notes (marquee or Ctrl+click), press Shift+G — they all get a gold/amber border
* Click any one of those grouped notes to move it — all notes in the group move together
* Mute one grouped note (Mute tool) — the whole group mutes
* Select any grouped note and press Delete — the whole group is deleted
* Select grouped notes, press Shift+Alt+G to ungroup (borders return to normal)

* Added a visible ruler strip at the top 14px of PianoRollGrid with bar numbers, beat tick marks, and a green triangle indicator showing the current playhead position
* Clicking anywhere in that ruler zone fires onSeek(beat) to seek playback to that position
* The onSeek callback chains: PianoRollGrid ? PianoRollContainer ? page ? StandalonePlayHead::seekTo()
Phase 6B — Piano Roll Note Scheduling
* PluginProcessor::processBlock() now scans all three piano rolls (layer, bass, drum) each audio block
* Notes whose startBeat falls within the current buffer window fire noteOn with sample-accurate timing
* Layer notes go into the allMidi buffer feeding mSynth; bass notes call mBassSynth.noteOn(); drum notes call mDrumSynth.triggerDrum() via the MIDI note ? row ? slot mapping
* PRPendingOff structs track scheduled note-offs; they fire at the correct sample offset in a later block
* Handles seeks/jumps (flushes all pending offs immediately) and stop (fires all pending offs before going silent)
* Pattern looping is handled via absolute beat math
