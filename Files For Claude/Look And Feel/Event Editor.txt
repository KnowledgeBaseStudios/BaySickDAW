This final piece of the UI library covers the **Event Editor** based on **Event Editor.png**. This interface is distinct from the Piano Roll and is designed for high-precision, automation-style data editing across a timeline.

---

## 1. Visual Schematic & Geometry

### **The Header (Control Bar)**
* **Visual**: A dark, slim horizontal bar with a high-contrast teal/green accent logo on the far left.
* **Automation Mode Toggles**: Features a "Automation editor" tab and an "LFO" radio button selector.
* **Control Cluster**: On the top right, there is a set of specialized hardware-style controls:
    * **Active LED**: A glowing green indicator.
    * **Mini Dials**: Three "Modern Domed" micro-knobs for **MIN**, **MAX**, and **TIME**.
    * **Value Readout**: A dark red rectangular display showing a single large digit (e.g., "2"), flanked by a "RANGE" label and a node-connector icon.

### **The Main Editing Grid**
* **Background**: Vertical "Zebra-Striping" logic. The grid is divided into bars (numbered 1–6+), where each bar has a subtle alternating dark-gray background to assist in rhythmic placement.
* **The Envelope Line**: A thin, glowing teal line (`#A0DB2B`) that runs across the grid.
* **Nodes**: Small, hollow circular points that represent automation keyframes.

### **The Target List (Bottom Pane)**
* **Visual**: A recessed list view with a header labeled "Target links."
* **Selection**: Active targets (e.g., "Master - Volume") are highlighted with a dark blue background and light gray text.

## 3. Special Interaction & Usage Logic

### **Event Editor Specificity**
* **Logic Instruction**: This UI component and its associated `LookAndFeel` are strictly for the **Event Editor**. This interface handles global or track-level parameter changes that are **not** contained within the Piano Roll's per-note editor.

### **LFO vs. Manual Mode**
* **UI Logic**: When the "LFO" tab is selected, the main grid should shift from displaying manual nodes to displaying a generated periodic waveform.
* **Snap-to-Grid**: Implement logic where nodes automatically snap to the nearest beat or sub-division unless a modifier key (like Alt) is held.
