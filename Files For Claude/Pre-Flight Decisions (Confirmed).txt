Item	Decision
Version naming	v1.9 first full build; v2.0 after testing/tweaks

FX Master Switch	Yes — bypassing reduces CPU (skips processBlock for all slots). Rack state is preserved (not deleted) when bypassed.
Undo history size	User-configurable in Options > General: 100 / 250 / 500 / 1000 steps.
Audio import	File > Import Audio (.wav, .mp3) + drag-and-drop onto Builder page.

    [InstrumentNode(s)] → [BassBuss]   ↗
    [DrumNode]          → [DrumsBuss]  ↗ (MasteringEngine wraps Master output)
